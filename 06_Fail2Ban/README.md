# Fail2Ban 운영 기준

- `sshd` Jail: systemd journal, action `nftables`
- `maxretry = 5`, `findtime = 600`, `bantime = 600`
- 영구 예외: `127.0.0.1/8`, `::1`, `192.168.0.3`(관리자), `192.168.0.4`(서버)
- `192.0.2.15` 문서용 테스트 IP: 수동 Ban→nftables 집합에 포함→관리 프로그램 Unban→규칙에서 제거 검증 완료
- 실제 SSH 네트워크 연결이 차단되는 시험은 별도(수동 방화벽 등록과 구분)
- FastAPI 로그인 실패 자동 차단은 **개발 범위에서 제외** (사용자 결정)

이 폴더의 관리 스크립트는 현재 대화에 첨부되어 있던 실제 `.sh`를 복사한 것입니다.
